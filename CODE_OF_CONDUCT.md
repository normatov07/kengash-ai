# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, welcome newcomers, and keep discussion about the work. Harassment, insults and personal attacks are not accepted in issues, pull requests, discussions or any other project space.

To report unacceptable behaviour, use the private vulnerability-report form on the Security tab or contact the maintainer through their GitHub profile. Reports are handled confidentially, and maintainers may remove content or contributors that break these rules.
